# 🌿 Plant Disease Detection

A Machine Learning and Deep Learning project exploring plant disease classification using Python, feature engineering, Logistic Regression, and MobileNetV2.

## 📖 About the Project

Plant diseases can negatively affect agricultural productivity and crop quality. Machine learning and deep learning techniques can help analyze plant data and identify patterns associated with plant diseases.

This project explores different approaches to plant disease classification, combining traditional machine learning techniques with deep learning to investigate their potential for agricultural applications.

## 🎯 Objectives

* Explore machine learning applications in agriculture.
* Investigate feature engineering techniques.
* Implement and explore Logistic Regression for classification.
* Study MobileNetV2 for deep learning-based image classification.
* Understand the model development and evaluation process.

## ⚙️ Getting Started

### Prerequisites

* Python 3
* pip
* Jupyter Notebook or Visual Studio Code

### 1. Clone the repository

```bash
git clone https://github.com/ChamiduPrabodya/Plant-Disease-Detection.git
```

### 2. Open the project folder

```bash
cd Plant-Disease-Detection
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

Activate it using Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

### 4. Install the required libraries

Install the dependencies required by your notebooks. For example:

```bash
pip install jupyter numpy pandas matplotlib scikit-learn tensorflow
```

### 5. Run the notebooks

```bash
jupyter notebook
```

Open the notebook you want to explore and execute its cells in sequence.
